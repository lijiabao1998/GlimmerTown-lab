# 微光小鎮·實驗線（GlimmerTown-lab）

> 本倉庫為《[微光小鎮 Glimmerville](https://github.com/lijiabao1998/glimmertown)》的獨立實驗線：**於 T420 分岔，自 T531 v12.87 起獨立演進**；與主線 `glimmertown` 的 `T` 卡號各自獨立，不合併回主線。

目前狀態：**v14.79 · T793**（2026-11-18）。

## 核心原則

- **美術第一**：實驗線的優先序為「美術 > 市民一生、效能、工具」，涉及全局色調、光影或密度的改動須先出對照圖由業主定奪。
- **迭代不改壞**：所有玩法與美術改動均須在開工前閱讀 [`docs/迭代不改壞標準.md`](docs/迭代不改壞標準.md)，並在提交前通過其第 8 節自檢與煙霧測試。
- **業主決策留痕**：所有方向性決定與日期記錄於 [`docs/DECISIONS.md`](docs/DECISIONS.md)。
