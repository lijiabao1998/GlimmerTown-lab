# T602 街上要有更多房子：超街區縮小＋裙樓不再鋪滿＋別墅不合併

**基線**：`1f49abe` T601  
**業主**：繼續。上一刀加了針塔／石材，但大街廓仍把整排 1×1 合成一塊玻璃板，遠距還是「同一棟」。

## 根因

1. `rciBlockOrigin547` 上限 6×7，一整條街一張精靈。
2. `podTower`／`point` 的 `ex` 佔地 `[0,1,0,1]`，裙樓鋪滿超街區＝玻璃地板上戳一根。
3. 別墅 `v` 仍會跟聯排合成大廳，花園屋消失。

T601 的新物種在 6×7 合併裡幾乎看不見。

## 改什麼

- 視覺合併上限 **4×4**（T548 的 6×7 仍是硬天花板，這一刀用更小的街廓）。`__noBlockCap602` 退回 6×7。
- 佔滿的裙樓改成前庭低板 `[.08,.92,.06,.38]`，塔坐在院子裡。`__noPodium602` 關閉。
- 別墅 1×1 不參加合併。`__noSpeciesMerge602` 關閉。

不改 tile、存檔、模擬。純繪製合併。

## 驗收

1. `blockMax602()` 預設 `[4,4]`，閥門開是 `[6,7]`。
2. 4×4 podTower 開關裙樓 CRC 不同。
3. 別墅 `rciSame547` 對鄰居別墅為 false（用測試種格）。
4. 煙霧綠；fp `--expect=block559`。

## 施工紀錄

- 煙霧綠 13.4s；moreBld602 7/7。別墅必須在 origin 自己身上短路成 1×1，否則西鄰聯排會把別墅吞成「非 origin 又不在簇裡」的黑洞。
- fp `--expect=block559`：`165e5de4 → 997a4336`。
