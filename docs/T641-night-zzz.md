## 1. 這一輪要解決什麼

T607 替夜裡準備了睡覺圖示（`bubbleFor607` 在夜深度 `nd>0` 時，住宅與商業回 `zzz`、工業不冒），但從來沒出現過（T619 補驗發現）：

- 泡泡由 `drawFestivalDay517` 呼叫 `drawStreetStories521(0)`，傳進去的夜深度寫死 `0`；
- 而 `drawFestivalDay517` 一入夜（`nightDepth>0`）就整段 return。

## 2. 改什麼／不改什麼

**改**

1. `drawFestivalDay517`：入夜時（`nd>0`）在 return 之前呼叫 `drawStreetStories521(nd)`，把真的夜深度傳進去；近景才畫（`_lodMini413` 時不畫），跟白天一樣。
2. 逃生閥 `window.__noZzz641` ＝ 夜裡不畫（舊行為）。
3. 自檢 `zzz641` 掛煙霧；版本 v13.46／T641。

**不改**

- 白天的泡泡（仍走原路徑、原來的 `0`）。
- 泡泡畫在夜色之前、會被夜色壓暗一些（業主選檔時看過同樣的圖）。
- 圖示、冒泡頻率（約一半建築、每 11 秒冒約 1 秒）。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `zzz641`**（煙霧常駐）：自己種一棟 1×1 住宅、一棟商業、一棟工業，時間設在冒泡的那一秒：夜深度 > 0 時住宅、商業回 `zzz`、工業不冒；夜深度 0 時住宅回白天圖示；閥門可關；夜間呼叫路徑存在。量完原樣還原。
2. **像素**（`probe641.js`，種子城住宅近景 z=2、午夜，掃一個泡泡週期）：新版畫出的泡泡數 > 0；關閥門時每一刻都是 0。
3. **煙霧** 3 連跑綠；GitHub Actions 綠；`fp.js --check` 綠。
4. **樣張**：午夜住宅近景冒 zzz 的放大圖（業主選檔時看過同一組）。
