# T653 — 被蓋住的窗不再亮燈

**輪次**：r100
**基線**：`96e849b`（v13.52／T647）
**狀態**：卡面（動手前）
**業主決定**：2026-09-25 決策單第三批「窗燈顏色（業主備註）」選 **「有些大樓玻璃被遮住之後，不應該窗戶的燈光依然被渲染」**（`docs/DECISIONS.md`）。T648–T653 六張卡一次佔號，一張一張做。

## 1. 這一輪要解決什麼

街區精靈（`makeBlockSprite547`）的白天圖 `g` 與夜圖 `ng` 分開畫：窗戶先畫（`g` 畫玻璃、`ng` 畫燈），之後前面的量體、屋頂、前院等只畫在 `g` 上把窗蓋掉，`ng` 上那扇窗的燈卻還在。夜裡燈就亮在紅瓦屋頂、前棟牆上（例：k1 lv2 2×4 v10，後棟平頂樓的窗燈亮在前棟紅瓦屋頂上）。

## 2. 改什麼／不改什麼

**改**：畫街區精靈時，`g` 上每一次不透明的塗畫（fillRect、路徑 fill／stroke、drawImage；有效不透明度 ≥ 0.85），同時把 `ng` 同一塊擦掉（destination-out）。這樣只有「畫燈之後沒被蓋掉」的窗保留燈光。半透明的疊色（牆帶、陰影）不擦。逃生閥 `window.__noOccWin653`（精靈快取鍵帶閥門）；自檢 `occWin653`；版本 v13.58／T653。

**不改**：窗燈的位置與機率；其他精靈（摩天樓 T516 等）這張卡先不動，量完街區精靈再看。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `occWin653`**（煙霧常駐）：合成測試——先在 g／ng 畫一扇窗和燈，再在 g 上蓋一塊不透明方塊：新版 ng 那塊燈被擦掉、沒蓋到的燈還在；半透明（α .3）方塊不擦；關閥門時燈都在。
2. **像素**（`probe653.js`）：k1 lv2 2×4 v10 夜圖落在前棟紅瓦屋頂範圍的燈像素新版 0（關閥門 > 0）；抽樣 k1～k3 街區精靈，夜圖燈像素總數的減少量逐張記錄，減少超過一半的逐張看圖確認不是誤擦。
3. **開機時間**：新舊各量一次開機到可玩的秒數，記錄。
4. **煙霧** 3 連跑綠；GitHub Actions 綠；`fp.js --check --expect=block559`。
