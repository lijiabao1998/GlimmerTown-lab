# T613 英美立面的冬季炊煙；遛狗牽繩橫跨畫面（業主圈的「斜著一條一條的東西」）

## 第二件：業主圈的斜線，不是美術，是 T523 的一個座標

業主截圖裡「道路有斜著一條一條的東西」，之前用雨絲、廣場磨痕、配電線、輕軌架空線都對不上。這次用兩支探針追到：

- `p_bisect.js`：同一場景逐一開 68 個逃生閥比對像素差——那條線在每一個閥下都還在，所以不是任何一層可關的美術。
- `p_hook.js`：掛鉤 Canvas 2D 的 moveTo／lineTo／stroke，畫一幀，把所有「≥60px、近水平」的線段連呼叫堆疊記下來。抓到 `drawCrowdLife522` 的 T523 遛狗人：`const dxw=sway+7*z2` 少加了人的螢幕座標 `sx`，狗的 x 變成絕對座標約 20px，於是每個遛狗的人都拉一條牽繩一路畫到螢幕左緣，橫過馬路和草地；狗本身則被畫在畫面最左邊。路多、人多的城裡，就是一條條斜線。

改法一行：`dxw=sx+7*z2`（閥 `__noLeashFix613` 保留舊行為給守衛用）。

自檢 `leash613`：找一格遛狗人會出現的路格（沒有就暫鋪一格、驗完還原），鏡頭移過去，掛鉤 stroke 畫一幀遛狗層：修正後 ≥60px 近水平長線 0 條；**關閉修正閥必須抓到 ≥1 條**（首紅＝目標釘）。實測 0／1。

另外查清但不是問題的：路面上一條條黃色短線是街道小物（`__noStreet` 一關就少），輕軌架空線的點線與軌道平行、在精靈內；遠海地平線的波紋線在地圖底下。

**基線**：`f86025c`＋T611 之後的工作樹（與 T612 同一次提交）  
**業主**：「把全部尾巴做完」。T606 卡尾巴之一：英美立面（T577 八款）的住宅冬天不冒炊煙，因為煙點是從 72px 舊圖集的偏移讀的，立面精靈根本沒有 `smoke608`。

## 場景

T608 把工業與冬季民居的煙改成「從街區精靈記下的煙囪頂冒」（`smoke608`），但那份記錄只有內建畫法會寫。走 `__facade577` 立面繪製器的街區（英式排屋、維多利亞、半獨立、宅邸、高街店屋；美式褐石、戰前公寓、主街店屋）畫了煙囪卻不記點，冬天整條街沒有一縷煙。

## 改什麼（Opus 5.5 執行，Fable 5.1 判）

- `makeBlockSprite547` 的 T577 掛鉤給繪製器的 ctx 加 `chim(x,y,top)`：繪製器每畫一根煙囪就記一個頂點到 `smk608`。八款繪製器都接上（uk1／uk2／ukhigh／us1／usmain 五支檔案，含主街店屋的後翼煙囪）。
- `chimVisible613`：煙囪畫完後可能被後畫的較高鄰棟蓋掉；記錄點如果正下方已經不是那根煙囪的帽頂色，就濾掉。usMainStreet 原本 52 點有 13 點會從光禿禿的屋面冒煙。
- 繪製器回傳 false 退回內建畫法時，撤掉它記過的點。
- 冬季炊煙的觸發從「住宅 k1」放寬到「住宅 k1 或英式高街店屋 k2」（`__noShopSmoke613` 閥）；煙色同民居。
- 自檢 `facadeSmoke613`：五類×四種尺寸×九款，每個記錄點都在畫布內、下方兩格不透明、正下方是煙囪帽頂色；開關掛鉤前後日夜圖指紋相同；內建精靈的煙點不受影響；端到端一排 3×1 排屋原點格的煙點都落在煙囪上。
- 閥：`__noFacadeSmoke613`（關掛鉤）、`__noChimVis613`（關過濾）。
