# T696 — 地標外擴前庭、周界綠籬不再蓋到前面的建築

**輪次**：r143
**基線**：`b2fcef5`（v13.99／T695）
**狀態**：卡面先推，施工中
**業主回報**：2026-09-29 看 T695 巴特西近照：「空的格子非法疊在建築上面，而不是正常的顯示在建築底部」。

---

## 1. 這一輪要解決什麼

T160 建築地坪在物件層畫（每棟建築畫精靈前，先鋪佔地磚，大型公共建築再外擴一圈人行石板前庭，再在佔地外一圈疏落擺圍欄／綠籬），整組用**建築自己的排序深度**畫；多格建築的深度是佔地最前角。

外擴那一圈在建築**後側**的格子，深度比建築淺；站在這些格子前面、深度介於兩者之間的鄰居建築會先畫完，前庭石板和綠籬接著畫上去，就把鄰居的屋頂、牆面蓋掉。石板是平的地面，看起來就像一格空地貼在建築上。

實測（種子城 5162026，鏡頭 lookAt(48,22) z=3）：
- 原點 (39,25) 的 5×5 公共地標 k139 排序深度 72.025；
- 它的前庭格 (44,24) 深度 68；
- 前面的工業樓 (45,24) 深度 69.024，先畫；
- 前庭石板在 72.025 才畫，蓋掉工業樓左半邊屋頂和牆。

關掉 T160（`__noPlaza`）工業樓就完整出現。

## 2. 改什麼／不改什麼

**改**：外擴圈上，深度比建築淺（`viewDep(tx,ty) < floor(o.dep)`）的格子，把該格的前庭石板、T594 使用痕、圍欄／綠籬小件抽出來，排進物件排序時用**那一格自己的深度**（略早於同格其他物件）。這樣它們畫在前面的建築之前，被建築正常蓋住。
- 條件、材質、雜湊、可見判斷都跟原本那段一樣（同一個判斷函式），只改畫的時機。
- 逃生閥 `window.__noRingDepth696`（執行期）＝回原樣。

**不改**：佔地磚、入口踏步、落地影；外擴圈前側的格子（深度不淺於建築，本來就沒有越位）；前庭與綠籬的範圍、材質、出現率。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `ringDepth696`**（煙霧常駐）：
   - 判斷函式：建築深度 d 時，深度 d−1 的格子算後側、d＋1 的不算；閥門下都不算；
   - draw 裡外擴圈兩段迴圈（石板、綠籬）都走同一個判斷；
   - 真的 `draw(.016)` 一次不擲錯。
2. **守衛 `probe696.js`**：種子城、鏡頭對著工業樓 (45,24)：
   - 用「關地坪」與「關地坪＋暫拿掉這棟」兩張做出這棟建築的像素遮罩；
   - 新版在遮罩內跟「關地坪」相同（差 ≤ 遮罩 1%），閥門版差 >500 像素（重現原本的錯）；
   - 全城鏡頭統計新舊差異像素與抽出的格數。
3. **對照圖給業主**：同鏡頭修前／修後（正午、午夜）。
4. **煙霧** 3 連跑綠；`fp.js --check` 全綠（物件層繪製順序，不動精靈）。
