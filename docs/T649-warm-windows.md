## 1. 這一輪要解決什麼

建築夜圖的窗燈是近白色（#fffbe5 一類），疊上發光層幾乎是純白，商場、玻璃樓整排窗變成白方塊。

## 2. 改什麼／不改什麼

**改**：推進發光層的建築夜圖（`s.night`、`s.nightCity`，含 T643 超街區分條）畫之前先染成暖黃（乘 #ffd48a、保留原透明度；每張圖染一次後快取），亮度不變。發光層兩條路徑（`nightCompose629` 與關遮擋舊迴圈）都照染。逃生閥 `window.__noWarmWin649`；自檢 `warmWin649`；版本 v13.54／T649。

**不改**：路燈、招牌、霓虹、車燈、`pushWindowLife446D` 的方塊窗燈（本來就是暖色）；窗燈位置與數量。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `warmWin649`**（煙霧常駐）：拿一張白色小圖染色，結果 R≈255、G≈212、B≈138（±3）、透明度與原圖逐像素相同；同一張圖第二次取到快取；閥門可關。
2. **像素**（`probe649.js`，住宅近景 (12,12) z=2、午夜）：亮窗像素的平均 B/R 比，新版明顯低於關閥門（偏暖）；正午新舊逐像素相同。
3. **煙霧** 3 連跑綠；GitHub Actions 綠；`fp.js --check` 綠。
