# T634 — 樣張城裡的棕色折線：種子城改了地形卻沒重算崖沿，留下隨機地形的「幽靈崖沿」

## 1. 這一輪要解決什麼

旋轉稽核看港區近景（Pages「近景」鏡頭）：河面上、草地上各有一串棕色雙線折線，看起來像柵欄，四個旋轉都在。

進場探針（暫存腳本，暫時改動已還原）：

- 那是 T24 的「高地內陸崖沿」：`el=1` 的高地格朝 `el=0` 的那幾條邊記在位罩 `em`，地面快取依 `em` 畫 `SPR.cliffEdge`（深褐線，加上 T153 補的岩層線）。地面是平的畫法，崖沿就只剩兩三條棕線。
- 種子城 `metroArtSeedWorld516` 先開一座隨機新城（有高地），再把 (1..49, 1..47) 整片的 `el` 設成 0、第 43 列以後改成水，然後重算道路位罩（`recalcAllMasks`）、鐵路位罩、岸邊泡沫（`computeFoam`），**唯獨沒重算崖沿**。`computeElMask` 只在 `newWorld` 與讀檔時呼叫。
- 結果：隨機地形的崖沿留在已經是平地、甚至是水的格子上。種子城 **103 格**的 `em` 與現況不符：13 格在水上、90 格在陸地，其中 15 格是該有卻沒有（展示區外圍的高地面向展示區那一側）。一般新城 0 格不符。
- 地形筆刷挖水時會把 `el` 一起清成 0，一般遊戲不會出現「高地上的水格」，所以問題只在種子城。
- 影響：業主在 Pages 看的就是種子城。8 個樣張鏡頭中，港區近景 6,226 像素、中景 3,345、遠景 2,050、住宅近景 192。
- 其他殘留旗標：展示區內 56 格有道路等級 `rc` 卻沒有 `road`，繪製看 `road`，無害，不動。

## 2. 改什麼／不改什麼

**改**

1. `metroArtSeedWorld516`：地形改完後呼叫 `computeElMask()`（與 `newWorld` 同一條）。
2. 逃生閥 `window.__noSeedEl634` 退回不重算。
3. 新增 `elStale634()`：數目前城裡 `em` 與「照現在的 `el` 重算」不符的格數；自檢 `seedEl634` 掛進煙霧。版本 v13.39／T634。

**不改**

- 崖沿的畫法（`SPR.cliffEdge`）與 T24 規則；崖沿該長什麼樣屬美術決定，另案（待辦「地形／堤防美術」）。
- 一般新城、讀檔、地形筆刷（本來就一致）。
- 殘留的 `rc`（無害）。
