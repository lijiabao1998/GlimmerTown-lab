## 1. 這一輪要解決什麼

每格草皮（`SPR.grass`）四邊畫了亮邊 #83c467（上兩邊）和暗邊 #66a04d（下兩邊），大片空地、河岸草坪上連成一張格子網。

## 2. 改什麼／不改什麼

**改**：地面層畫草地格時，改用「邊線往這格草色靠六成」的版本（第一次用到時由原圖產生、快取；草色取格子中央平均）。季節版、高地版同樣處理。逃生閥 `window.__noGrassGrid651`（地面快取鍵帶閥門）；自檢 `grassGrid651`；版本 v13.56／T651。

**不改**：原精靈 `SPR.grass`（留給閥門與其他用途）；沙地、水面、道路。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `grassGrid651`**（煙霧常駐）：取一張草地精靈，邊線像素和中央草色的平均色差，新版不到舊版的一半；中央像素逐像素不變；快取生效。
2. **像素**（`probe651.js`，(12,40) z=1、正午）：新舊有差異；草地上亮邊色（#83c467±4）像素新版比關閥門少八成以上。
3. **煙霧** 3 連跑綠；GitHub Actions 綠；`fp.js --check` 綠。
