# T701 — 地標專屬施工：巴特西、大笨鐘（第十三批 13-1 C 的地標部分）

**輪次**：r148
**基線**：T700 完成後的 main
**狀態**：卡面先推，等 T700
**業主決定**：2026-09-30 決策單第十三批 **1C**，1-4 **③**、1-6 **a**（`docs/DECISIONS.md`）。業主貼回時附上大笨鐘那一列的圖說：「逐皮砌石、塔頂平台跟著牆往上爬、吊桿在塔前；鐘室→鐘盤→鐘樓拱廊→鑄鐵尖頂」。

---

## 1. 這一輪要解決什麼

T700 之後，地標也走通用施工：從精靈推出的量體加一般鷹架、塔吊，沒有地標自己的步驟。C 要巴特西、大笨鐘各有一套照真實蓋法的工序。

## 2. 改什麼／不改什麼

**改**：照決策單原型 bespoke 軌（`scratchpad/b13/bespoke/x13bes.src.js`，resync 版，v14.03＋generic 第四版上拍的那一版）施工。
- 巴特西：
  - 地面：放樣、圍籬、開挖、打樁、澆筏基、回填，同時豎起一台動臂塔吊。
  - 主體：主廳紅丹鋼骨籠、磚牆逐皮往上砌；四座塔座西半先、東半後。
  - 煙囪：四支，西側兩支先、東側兩支後，每支分四節滑模，塔吊把節段吊上去。
  - 收尾：拆塔吊、拆鷹架、清場，街燈和煙囪紅頂燈完工那一刻才亮。
- 大笨鐘：
  - 地面：樁群、筏基、石砌台基。
  - 塔身：逐皮砌石，塔頂平台跟著牆往上爬，吊桿在塔前。
  - 上部：鐘室→鐘盤（金框、乳白玻璃、指針）→鐘樓拱廊→鑄鐵尖頂。
  - 收尾：拆平台、拆吊桿，兩盞街燈最後亮。
- 夜燈照 1-4③，第③級全套。
- 跟 T700 並存：本卡擁有的兩座地標不進 T700 的收尾與細節名額。
- 逃生閥 `window.__noConstr701`（執行期）＝兩座地標回到 T700 的通用施工。

**不改**：
- 模擬（工期、耗鋼、存檔）；地標工期 ×2（1-6a）。
- 其他地標（西敏宮等）沒有施工檔，照 T700。
- 大笨鐘鐘盤、指針的先後照原型；史料待查的部分記在第 7 節，不自己改順序。
