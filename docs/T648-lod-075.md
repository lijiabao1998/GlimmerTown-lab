## 1. 這一輪要解決什麼

`draw()` 的 `lodFar=z<1`：鏡頭一縮到 1 倍以下，窗燈、路燈、水面紋理、樹的搖動、貼牆細節等一起不畫，夜裡整座城變成一片暗藍；樣張頁的「中景」0.75 倍正落在這裡。

## 2. 改什麼／不改什麼

**改**：`lodFar` 的門檻從 1 改成 0.75（`z<0.75` 才省略）；`lodMini`（0.5）不動。逃生閥 `window.__noLod648`＝門檻回到 1。自檢 `lod648`；版本 v13.53／T648。

**不改**：各功能自己的縮放門檻（例如貼牆細節 z≥0.9、近景細節 z≥1.22）；0.75 倍以下的省略內容。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `lod648`**（煙霧常駐）：門檻函式 z=0.8 → 不省略、z=0.7 → 省略、z=1 → 不省略；關閥門時 z=0.8 → 省略；`draw` 用的是門檻函式。
2. **像素**（`probe648.js`，港區 (36,36)、0.8 倍、午夜）：新版畫面亮像素（亮度 > 150）比關閥門多；0.6 倍新舊逐像素相同（仍省略）。
3. **效能**：0.8 倍白天、夜晚各量 forceDraw 中位數，新舊並列記錄（雲端只記不判，手機要業主實測）。
4. **煙霧** 3 連跑綠；GitHub Actions 綠；`fp.js --check` 綠。
