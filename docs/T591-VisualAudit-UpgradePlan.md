**薄／缺（本目標的施工面）**：
1. **建築年齡風化＝零**：`bd.age` 存在但只用於施工進度；風化層全是天氣驅動（T430 濕/雪）。

   ⇒「被長期使用過」的痕跡是最大缺口。
2. **空置地格過渡地面**：zoned-but-empty 格僅裸草/平板（r32 已證）——沒有整地土、
   基礎板、建材堆、雜草、臨時停車等「正在變成城市」的中間態。
3. 屋頂設備密度（roofKit559 有但密度參數保守）；招牌新舊差異未掛 age。

## 4. 不可破壞的耦合（施工紅線）

- **fp.js 指紋棘輪**：任何 sprite 像素變動必須走 `fp.js --expect=<家族>`，家族樹 151 族
  零誤傷；block559 為偽家族需宣告。
- **決定性鐵律**：位置/款式只用 streetHash/seed；禁 R()/Math.random()；同 visT 重繪恆等。
- **save/模擬**：不改 tile schema、不消耗模擬 R()、不寫 save；純 draw-side + 逃生閥
  `__noXxx` + 計數器慣例。
- **detailPermit432 預算**：新增微細節必須掛同一預算系統（低縮放/高密區自動降噪）。
- **perf 比值棘輪 ±25%**：每輪跑 perf.js --check。
- draw 迴圈 tie-break 已是 T585 視圖座標（勿回退）。
