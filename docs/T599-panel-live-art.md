# T599 二級菜單即時刷新 + 施工場加密 + 近距立面第二層

**基線**：`377b907` T598 HUD 每幀刷新  
**業主原話**：美術細節不夠，要更細緻的施工動畫和更細緻的建築描繪；很多按鈕點開以後，遊戲在走，二級菜單內顯數據不跟著刷新。

## 改什麼

1. **二級菜單跟畫面走**  
   市政指揮中心（含人生分頁）與建築 inspect 殼（`.ins461`）在 `frame` / 隱藏分頁 250ms 接手路徑各 tick 一次。簽名（資金、人口、職位、幸福、日、天氣、垃圾、選中建築 age/lv/供電/火/罪/病）沒變就跳過。有焦點在 input/textarea/select 不重繪。市長辦公室已有 250ms watcher，不搶。重繪保 scroll，且 `__panelSilent599` 避免把手機 bottom sheet 打回 auto。
2. **施工場加密**（`__noConstrDetail599`）  
   前置場：第二工人＋手推車、流動廁所、發電機、交通錐；age0 加傾卸車；age1 攪拌車出料；鋼骨期塔司室。升起期：樓板工人＋兩側立桿、吊鉤磚棧。
3. **近距第二層**（`drawNearZoom599`，`z>=1.22`）  
   住：窗下花箱／陽臺欄杆／百葉。商：雨棚＋玻璃高光。工：牆腳黃黑條＋落水管。掛 `detailPermit432` layer 599。遠距剪影不改。

## 不改

- 存檔、模擬 RNG、tile schema、主線、8123、8199 看城埠。
- 不碰市長辦公室既有 watcher。
- 電力／水務等其它 `cmdRoot457` 子中心本刀不自動刷新（h3 不是「市政指揮中心」）。
- 不新開污漬環。

## 逃生閥

- `window.__noPanelLive599`：菜單回到開時快照。
- `window.__noConstrDetail599`：施工場回到 T259 密度。
- `window.__noNearZoom599`：近距第二層全關。

1. 指揮中心開著改 `money`/`pop`/`day`，面板數字變，不必關再開。
