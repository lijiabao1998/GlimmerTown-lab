## 1. 這一輪要解決什麼

T636 之後把同一套「掛點落在不透明像素上嗎」的稽核延伸到 T403 農牧動態（暫存探針）：

| 動態 | 結果 |
|---|---|
| 大農場 k53 拖拉機路徑（33 點） | 32/33 在田裡 |
| 農戶 k22 灑水器、牧場 k23 雞群、穀倉門 | 全部在建築上 |
| **農戶 k22 農夫**（站位範圍取 11 點，6 個變體都一樣） | **只有 6/11 在精靈上**：整排站位在農地菱形的下緣外面，兩端懸空 |

- 農夫站位 `x = 68 + (h−0.5)·90`、`y = 134 + h·8`（h＝格子雜湊，0～1），是 T609 重畫前的舊農戶圖座標。
- T609 新圖（136×150，錨點 (68,148)）的農地是 2×2 菱形：作物田在左半，農舍在右上。舊站位貼著菱形下緣、左右兩端超出菱形。
- 約 40% 的農戶會出現農夫（`streetHash<.4`），其中大約一半站到田外。

## 2. 改什麼／不改什麼

**改**

1. 農夫站位：精靈自帶 `farmerPath`（`[x0,y0,x1,y1]`）就照它；沒帶的 T609 新圖改沿作物田裡的一條斜線 `(34+30h, 118+14h)`（左下作物田，順著田壟方向）；舊圖照舊式。
2. 逃生閥 `window.__noFarmer637` 退回舊站位。
3. 自檢 `farmer637` 掛進煙霧。版本 v13.42／T637。

**不改**

- 農夫的畫法、上下擺動、出現機率；拖拉機、灑水器、雞群、穀倉門。

## 6. 施工紀錄（如實，含失敗）

- **卡面寫錯了舊式**：卡面寫 `(68+(h−0.5)·90, 134+h·8)` 同一個 h；實際 x、y 用兩個不同的格子雜湊（4041、4042）。新站位沿用：4041 決定沿斜線的位置，4042 只給 ±2px 的小抖動。
- **第一版自檢只驗了基本圖**。探針實拍還有 3 座農戶站在田外，追到繪製時會依季節與生長階段換成 `farmSea`／`farmGrow` 裡的換色版，它們沒帶 `__t609`，退回了舊式。改成看同一變體的基本圖，自檢也改成連 72 張換色版一起驗。
- 探針第一版把整幀所有農夫藍衣都算到同一座農戶上（一幀裡有幾十座），誤報「54 座全在田外」；改成只算落在這一座站位範圍附近的。
- **沒做成的：**
  1. 新站位是固定的一條斜線，沒逐張依作物田的實際形狀擺；以後重畫農戶可在精靈上帶 `farmerPath`。
  2. 大農場拖拉機路徑 33 點有 1 點落在精靈邊緣外（沒動）。
