# T588 — 個體跟隨（市民一生三原型之三）

**輪次**：r37　**基線**：T587（commit 6c632f8）　**狀態**：完工

## 背景

AUTORUN 甲類「市民一生」三原型：履歷檔案（T533 已有）、事件流（T535 已有）、
**個體跟隨**（缺）。本卡補齊：鏡頭跟著一個市民，看他通勤、工作、回家。

## 改什麼（純渲染層；不進存檔、不消耗 R()、不改模擬語意）

1. `follow588Tick()`：每幀（frame 主迴圈 advance 後、draw 前；rAF 停擺接手路徑同）把
   相機對準被跟蹤市民——通勤中（at===2）跟 `fx/fy` 浮點座標，室內停在住家格
   （`hx+.5,hy+.5`）。zoom<0.9 時抬到 0.9（跟人要看得到人）。
2. `follow588Start(idxOrCitizen)`／`follow588Stop(msg)`：狀態存 `window.__follow588`
   （session-only）；badge DOM（名字＋通勤中/室內＋停止鈕）。
   `__noFollow588` 逃生閥。
3. 履歷面板（showLifeResume533）尾部加「🎬 跟隨他（原型三）」按鈕。
4. GV 導出 follow588Start/Stop/Tick/Selftest；測試推進出口
   `GV.testAdvance588(dt)`（test-only，T534 先例）。
