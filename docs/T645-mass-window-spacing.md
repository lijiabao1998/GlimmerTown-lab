## 1. 這一輪要解決什麼

超街區的第二量體（裙樓、側翼，`massBox568`）用固定窗距畫窗：商業每 4px、其他每 3px 一扇，比主樓密，遠看偏雜。

## 2. 改什麼／不改什麼

**改**

1. `massBox568` 每排窗隔一扇畫一扇（窗距加倍），排距不變。
2. 亂數照舊每個原位置都抽（被跳過的也抽），留下的窗亮不亮、屋頂配件都跟改前一樣——只少了一半的窗，其他不動。（決策單實驗碼沒有照抽，屋頂配件跟著亂數位移；正式版刻意不帶這個副作用。）
3. 逃生閥 `window.__noMassWin645`＝舊式，精靈快取鍵帶閥門狀態；自檢 `massWin645`；版本 v13.50／T645。

**不改**

- 主樓的窗、排距、窗寬、顏色。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `massWin645`**（煙霧常駐）：在小畫布上直接呼叫 `massBox568` 畫一個量體，數玻璃色像素：新版約為關閥門的一半（0.4～0.6）；兩次呼叫之後亂數產生器停在同一個位置（亂數照抽）。
2. **像素**（`probe645.js`，種子城住宅近景 z=2、正午）：新舊畫面有差異，差異只落在建築上（地面、道路逐像素相同）。
3. **煙霧** 3 連跑綠；GitHub Actions 綠；`fp.js --check` 綠。
4. **樣張**：住宅近景、中景。
