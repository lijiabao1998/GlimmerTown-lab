## 1. 這一輪要解決什麼

T620 樣張頁的「住宅近景」裡，好幾棟聯排屋被**純灰、沒紋理的平板**蓋掉一塊，右側兩棟樓的牆上各浮著一塊**灰三角**。這是最礙眼的一類瑕疵。

### 進場探針（`probe621.js`）

在遊戲畫布上掛 `drawImage`／`fill`／`fillRect`／`save`／`restore`／`clip` 鉤子，`forceDraw` 一次，追「這個像素最後是誰畫的」。

1. 灰板的顏色 (174,176,168)／(168,170,176) 正是 T160 的 64×32 鋪面地磚。
2. 關掉 T555 分段（`__noOverlap555`），7 個查詢點全部變回建築本身的顏色 ⇒ 問題出在 T555 分段繪製。
3. 只關掉 T555 的「吸收小樓」，7 點仍是灰 ⇒ **不是**吸收（中途推錯一次，如實記）。
4. 四個旋轉方向量灰板面積（T555 開 vs 關）：rot 0 多 10,919 px、rot 1 多 5,505、rot 3 多 4,105、rot 2 幾乎沒有（−166）。
5. 列出蓋在灰板上那張建築圖的**每一段**：較早的分段已經把建築畫在查詢點上（點在該段裁切柱內）；之後另一段在貼自己的圖之前，先在 61408 行把**起點格的地磚**重鋪一次，蓋掉了前面的建築。

### 根因

- T160「建築地坪」（61379～61443 行：鋪磚、落地底座陰影、入口踏步、圍欄）對超街區只處理起點格（`pSz=1`，位置 `(o.x,o.y)`）。
- T555 把超街區切成多條對角分段，**每一段物件都帶同一個起點座標**，所以每一段都重鋪一次起點格。
- rot 0 時起點格屬於最先畫的分段 ⇒ 後面的分段重鋪地磚，把第一段已畫好的建築蓋掉。rot 2 時起點格是最後一段 ⇒ 沒事。與量到的四個方向完全吻合。
- T575 早就修過同一類問題（61503 行「超街區切條時地面效果只在第一條畫」），這段 T160 漏掉了。
