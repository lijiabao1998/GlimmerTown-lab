# T582 — 超街區立體感修復（工業屋頂回歸＋量體分割）

## 背景與證據

業主截圖指出兩件事：建築缺乏立體感、建築互相疊蓋不正常。r32 診斷（seed 5162026，
shots/T582_*.png）確認三個事實：

1. **k=3 工業合併量體無屋頂**。`makeBlockSprite547` 的屋頂段分支為
   `__noPitch553||flat → 平頂`、`!typ → 鋸齒/雙坡`、`k===1 → …`、`k===2 → …`，
   **typology 開啟（預設）時 k===3 沒有任何分支** → 牆畫了、頂沒畫，屋頂色又與
   地坪同灰，整塊讀成平板。`!typ` 分支裡本來就有鋸齒（`sawtoothPara547`），
   證明意圖存在，是 typology 重構時掉的。
2. **整街廓合成單一量體**。`rciBlockOrigin547` 上限 6×7，種子城街廓 5 寬 →
   整個街廓一塊 mass＋lotFill 灰地坪；相鄰街廓同色相接、地面陰影再疊 14px，
   視覺上融成巨型板（「疊建築」的觀感來源）。
3. **隔離實驗**：`__noSuperblock547=1` 時工業區變回密集 1×1 鋸齒廠房（健康）；
   `__noTypology556=1`、`__noFacade577=1` 對灰板無效。空地灰板是空 zoned 格的
   地坪藝術（種子城 (x+y)%17 斜線洞造成大面積空地），非本卡範圍，記入日誌。

## 改什麼

僅 `makeBlockSprite547`（快取鍵加 `_noparcel` 後綴），不改 tile/save/模擬/R() 消耗。

- **A.（原案，已否證撤下）**k=3 屋頂分支——實查代碼後發現 typ 路徑末端的
  `else` 兜底分支**已有** `sawtoothPara547`，k=3 合併量體有鋸齒屋頂。
  截圖中「無屋頂灰板」經 `__noSuperblock547` 隔離實驗與種子函式比對，
  確認是 seed showcase 特殊建築（174/139/135/136 的 5×5 展示物）與空地地坪，
  非超街區缺陷。撤下。
- **B. 大街廓量體分割（本卡施工項）**：`bw*bh>=6` 且原型無 `ex` 時，沿 v（進深）
  把原型 box 切成主量體＋第二量體（v 中線 ±0.04 巷道，ex 走既有 `massBox568`，
  hm×0.85）。巷道露出 lotFill 地坪，視覺上從「一塊板」變「前後兩棟」。
  b3-b2<0.5 的淺原型、villa、既有含 ex 原型不切。逃生閥 `window.__noParcel582`。

## 額外發現（記錄，不施工）

- 業主視角可能含旋轉；`objs` 深度 tie-break `dep:d+y*.001` 用世界 y，
  旋轉下與螢幕深度不一致（r≠0 時相鄰切條可能錯序）。旋轉重現實驗未成功
  （Runtime.evaluate 無法改到該 `viewRot` 綁定），列 T583 候選。
- 合併 sprite 像素普查（probe582b）：T577 接手塊的主導色為屋頂灰
  `#4c4845`（bucket 4,4,4，2_2_5x5 達 3993 取樣 px）——「全城同一暗灰」
  的量化證據。配色層修復列下一卡（連同 T577 街景指紋 CRC 一併處理）。

## 不改什麼

- 1×1／小街廓（bw*bh<6）、villa、既有含 ex 原型（courtyard/point/twin/dept/podTower）
- T577 立面繪製器接手的主量體畫法（只在 ex 合成時生效，路徑不變）
- T555 切條、深度排序、空地地坪藝術（下一卡候選）

## 驗收條件（動手前寫死）

1. 守衛 G1（屋頂）：k=3、5×5、v=0 的合併 sprite，在主量體 roof quad 中心取樣，
   顏色 ≠ 地坪灰（#6a6862/#6d675d 系），且 roof 區域 distinct 色數 ≥3（鋸齒明暗）。
   `__noRoofFix582=1` 時此斷言必須失敗（反向驗證）。
2. 守衛 G2（分割）：k=2、5×5 sprite 的量體 bbox 內，沿 v 中線存在一條 ≥2px 寬、
   顏色 = lotFill 地坪的縱向巷道。`__noParcel582=1` 時必須失敗。
3. 煙霧測試綠；日/夜樣張 shots/T582_after_day.png、T582_after_night.png。
4. 幀率：seed 城日間 draw 幀時間不劣化超過 10%（與施工前同法量測）。
