# T550 — 橋樑護欄燈（日夜雙層）

**輪次**：r19　**基線**：`f72d262` T549 v13.02　**狀態**：✅ 三件成立，已 commit
**選題**：記分卡佇列第一名 `bridgeMaster480A`（總分 66.9%、240 葉、重力 79.4，已連三輪未動）
**依據**：鐵律「先有燈具，才有光」＋ TheoTown 夜層規格（夜圖獨立、燈光須與白天畫出的燈具對齊）

## 1. 探針
`applyT480ABridgeAssetReconstruction()` 產生 5 條路寬 × 3 風格 × 16 mask ＝ 240 片橋面，
護欄畫在**暴露邊** `diaEdge(g,(~m)&15,...)`。**橋面完全沒有夜圖**（記分卡軸⑥ 50% 的地板）。
繪製點只有一處（14346）；`nightDepth` 是 `draw()` 的區域變數，地面層取不到。

## 2. 驗收條件（動手前寫定）
1. 沿**暴露邊**（＝真的有護欄那幾邊）插燈柱與燈罩，白天可見。
2. 夜圖只亮燈罩與相鄰「白天已畫」的實體像素（鐵律），且與日圖同幾何**必然對齊**。
3. 只有夜間合成，日間逐像素不變（既有不變量）。
4. 逃生閥 `window.__noBridgeLamp550`；零 R()、不進存檔、整數像素。
5. 指紋差 == 宣告清單；棘輪不退步；A/B 日夜各一張；煙霧綠。
6. **夜圖覆蓋率必須上升**（量化驗收）。

## 3. 施工
- `draw()` 內曝露 `window.__nd550=nightDepth`（純讀值，讓地面層拿得到夜間係數）。
- 生成器：沿暴露邊每 5 步插一盞（燈柱 `#343a42` 3px ＋ 燈罩 `#e8e0c8` 1px），幾何與 `diaEdge` 同式。
- 夜圖：同尺寸新畫布，只填燈罩 `#ffe9a6` ＋ 四鄰「白天實體」像素 `rgba(255,214,130,.42)`。
- 繪製點：`nd550>0.25` 時以同 transform 合成夜圖。

## 4. ★ 施工紀錄：一個自作自受的量測假象 ★
第一版把夜圖存進**平行陣列** `SPR.bridgeNight480A`。結果指紋台**配不到日夜對**，
把 225 片新夜圖算成「新增的日圖」⇒ **夜圖覆蓋率反而掉到 28.4%**（假退步）。
**修法**：改成與 `bld`／`ped` 同構的 `{img,night}` 單筆結構（消費端只有 1 處，安全），
指紋台立刻正確配對 ⇒ 覆蓋率 **31.0% → 40.5%**。

**教訓：資料結構要配合量測工具既有的約定；否則「做對了」會顯示成「退步了」。**
