# T607 街頭敘事泡泡：一棟一個、貼真屋頂、少而清楚

**基線**：`daef1f7` T606  
**業主**：「你全部做完吧」。T606 收尾時，草地上的白色小晶片還在。

## 場景

總覽圖上有幾十個白框深心的小晶片。追查（`probe607b.js` 在主畫布上找白框深心像素群，`probe607c.js` 攔下畫到那些點的繪製呼叫）：
它們是 T521「街頭敘事」的市民情緒泡泡，由 `drawStreetStories521` 在節慶層畫出。住宅是愛心／微笑、商業是音符、工業是齒輪。

毛病有四個：

1. 逐格判斷。超街區的每一格都各自冒泡，一塊 4×4 最多同時冒三四個。
2. 太多。11 秒週期的前 23% 都在冒，也就是任何時刻約四分之一的建築掛著泡泡，任何縮放都畫。
3. 高度寫死在離地 58+lv×8 像素，不看建築多高。矮房的泡泡浮在草地上空，高樓的泡泡陷進牆裡。
4. 工業的齒輪畫成 3×3 灰格加深色中心，看起來就是一個深色方塊。

## 改什麼

- `bubbleFor607`（純函式，繪製和自檢共用）：
  - 一棟一個：用 `rciBlockOrigin547` 判斷，超街區只有原點格能冒。
  - 約一半建築會說故事，週期前 9% 出現，淡入淡出。
  - 縮放小於 1 不畫。
  - 用那棟實際的街區精靈，找第一列有量體寬度（≥5px 或寬度 10%）的像素，尾巴停在它上方三格。略過煙囪、天線這類細件。
- `bubbleIcons607`：11×11 圓角泡泡加尾巴，5×5 整數像素圖示（愛心、笑臉、音符、有齒有孔的齒輪、Zzz），日夜兩套底色。以 `round(z)` 整數倍放大，像素不糊。
- `__noBubbleFix607` 退回 T521 舊畫法。
- 版本 13.18／T607。T606 自檢的版本錨從「等於 T606」改成「≥T606」，否則每升一版就紅。

不改存檔、模擬、精靈。

## 驗收（動手前寫）

自檢 `storyBubble607`：圖示齊全、齒輪中心鏤空；超街區非原點格從不冒泡；冒泡比例平均 ≤8%、最大 ≤15%；11 秒內確實有人冒；泡泡尾巴都在屋頂之上；縮放 <1 不畫；逃生閥在。煙霧綠、指紋零變動、效能門檻內。1.5 倍對照我自己看過。

## 施工紀錄

- 煙霧綠 22.1s；`storyBubble607` 9/9、`wallDetail606` 16/16。
- 指紋 0／0／0。效能全部在門檻內（無頭環境雜訊大，這輪反而全部偏高）。
- **自己抓到自己的**：
  - 第一版自檢拿城裡現有建築量，但煙霧測試的城是空的，量到 0 棟而紅燈。改成照 T603 的做法，在陸地上暫時種 10×10 格工商交錯（不會合併）加一塊 4×4 住宅超街區，量完逐格還原。
  - 100 棟樣本下「任一時刻最大比例」有抽樣起伏（期望約 4.7%，44 個時點取最大會到 9–10%），原本 ≤8% 的單一門檻會誤紅。改成平均 ≤8%、最大 ≤15%。舊規則在同一批建築上平均約 23%。
  - 第一版把尾巴停在「最頂一列不透明像素」，結果工業建築的泡泡黏在煙囪尖上。改成找第一列有量體寬度的像素。
