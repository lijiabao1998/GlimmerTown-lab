# T606 疊畫落位：舊微雕層不再浮在新建築外

**基線**：`68cd99e` T605  
**業主**：「你全部做完吧」——接在 1.5 倍近景看到紅橙橫條橫過牆面、淡青方塊浮在草地上之後。

## 場景

關掉 T599 近距層再拍一次，橫條和方塊全部消失，來源確認。往下查發現不只 T599：
T421–T431、T447、T591、T593、T599 這整批微雕疊畫，都是為舊的正面圖寫的，用「外框寬×比例、外框底邊」定位。
住商工改走等距街區精靈之後，外框下緣兩角是透明的，這批層就落在建築外。

量測（`probe606.js`，種子城五個位置，105 棟，z=1.5）：

另一個病：超街區切成斜條分次畫，剪裁在建築本體畫完就 restore，所以這批層每條斜條都整張重畫，半透明一直疊。

## 改什麼

1. **等距街區精靈（`s.__t547`）不吃外框比例疊畫。** `legacyOverlay606(s)` 當閘門。
2. **舊圖建築的本體層畫進離屏、剪進剪影再貼回。** 本體 10 層（424/591/593/426/421/425/430/423/431/599）。地面 8 層（447 系列、422、429）照舊，那些本來就畫在地上。
3. **貼牆層 `drawWallDetail606`**：把 T591 風化和 T599 近距細節的原意，重寫成真的貼在牆上。
   - 街區產生器在 `__t547.wall` 記下主量體的 W／S／E 角與牆高。
   - 在精靈像素空間畫，逐像素剪進「牆多邊形 ∩ 精靈不透明」，依精靈快取（上限 520 張）。
   - 風化：雨漬沿簷口往下、牆腳苔垢、簷下積灰，age 分三段加深。z≥0.9。
   - 近距細節：住商牆腳花台、垃圾桶、立牌，側牆冷氣機；工業牆腳工安斜紋、棧板、側牆立管。z≥1.22。
   - 畫在超街區斜條的剪裁**裡面**，不會逐條疊加。
   - 英美立面街屋不疊：它們在精靈內自帶門窗花台。
4. 版本 13.17／T606。`fp.js` 改讀目前版本字串（原本讀 T534 凍結的建置紀錄，所以指紋檔一直標 12.89／T534）。

逃生閥：`__noOvFix606` 退回舊行為；`__noWallDetail606` 關貼牆層；貼牆層沿用 `__noAgeW591`、`__noNearZoom599`。

不改存檔、模擬、精靈像素。
