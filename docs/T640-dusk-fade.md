## 1. 這一輪要解決什麼

`daylight()` 的晨昏強度 `dusk=(d>0&&d<.30)?(0.30-d)/.30:0`：太陽剛落下（d→0⁺）時最大（≈1），下一刻 d=0 就歸零 ⇒ 暖橙疊色、天空地平線輝光（T211）一下子消失。T619 補驗在黃昏逐格圖上看到（ph 0.745→0.76），新舊夜色都有，T149 起就是這樣。

決策單的 B 檔圖是用臨時實驗碼拍的：日落後用太陽的負高度 `sr=sin((ph-.25)·2π)` 把 dusk 從 1 線性降到 0（sr 從 0 到 −0.25，約 4 秒）。

## 2. 改什麼／不改什麼

**改**

1. `daylight()`：**只在日落那一側**（ph ≥ 0.5）、太陽已落下（d=0）時，`dusk = max(0, 1 + sr/0.25)`。
2. 逃生閥 `window.__noDuskFade640` ＝ 舊公式。
3. 自檢 `duskFade640` 掛煙霧；版本 v13.45／T640。

**不改**

- `b`、`d`、`ph`（夜色深淺、所有看 b 的門檻都不動）。
- **日出那一側**：天亮前冷藍光也是一下子出現，但業主只選了日落；日出要不要淡入另列待決（`docs/DECISIONS.md`）。
- 疊色的顏色與強度係數（橙 0.16、藍 0.14、輝光 0.09／0.26）。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `duskFade640`**（純函式，煙霧常駐）：ph 以 0.0005 步進掃 0.70～0.82，相鄰兩點 dusk 的最大跳變：新版 < 0.05；關閥門時 > 0.5（守衛有效）。ph ∈ [0,0.5) 新舊逐值相同（日出側不動）。正午、午夜 dusk＝0。
2. **像素**（`probe640.js`，種子城住宅近景 z=1.5）：ph 0.745（日落前）新舊逐像素相同；ph 0.22（日出前）新舊逐像素相同；ph 0.755（剛落下）新舊不同。
3. **煙霧** 3 連跑綠；GitHub Actions 綠；`fp.js --check` 綠。
4. **樣張**：日落前後四格修前修後（業主選檔時看過同一組）。
