## 2. 改什麼／不改什麼

**改**

1. 摩天樓警示燈：沒有自帶 `warnAt` 時，改用**精靈的最高點**（最上面一列不透明像素的中點＝天線尖或屋頂尖；由精靈的 alpha 算一次、存在精靈上）。
2. 旗子：精靈自帶 `flagAt` 才掛；沒帶的只有**舊圖**（不是 T479／T516 新圖）才退回舊預設座標。體育場新圖自帶靜態旗子，不再疊一面浮空旗。
3. 氣象站雷達：沒有 `radarAt` 的 T479 新圖，若預設點浮空，改用精靈最高點（桅杆頂）。
4. 逃生閥 `window.__noAnchor636` 一次退回舊座標。
5. 自檢 `anchor636` 掛進煙霧。版本 v13.41／T636。

**不改**

- 自帶錨點的新圖、已經貼在建築上的掛點（學校、市政廳、機場、風車、電廠、焚化廠、氣象站 v1／v2）。
- 動態小物本身的圖、動畫節奏；精靈本身（指紋不變）。
