# T671 — 倫敦馬廄街屋的煙囪不冒煙

## 1. 這一輪要解決什麼

T656 的倫敦馬廄（住宅 1×1 lv1 v=5，`REG.ukMews`）在煙囪帽上登記冒煙點：`ctx.chim(cx, cy-wallH-11, '#6b3f2a')`。
T613 的 `chimVisible613` 會讀冒煙點正下方一格的像素，跟登記的顏色比，不一樣就當成被別的量體蓋掉、把煙刪掉。
馬廄那一格畫的是煙囪帽 `#a35a37`，不是 `#6b3f2a`，所以**每一棟馬廄的煙都被刪掉**。

進場探針（本 session，種子無關，直接建精靈 `block559.make(1,1,1,1,5)`）：

| 條件 | `smoke608` |
|---|---|
| 現況 | `[]`（0 個） |
| 關掉 T613 可見性檢查 `__noChimVis613` | `[[65,45]]`（1 個） |
| (65,46)、(65,47) 的像素 | `(163,90,55)`＝`#a35a37` |

其他英式立面（`ukTerrace` 等）登記的顏色就是煙囪帽最上面那一格的顏色，所以會冒煙；只有馬廄對不上。

## 2. 改什麼／不改什麼

**改**：馬廄登記冒煙點時用煙囪帽實際的顏色 `#a35a37`。逃生閥 `window.__noMewsSmoke671`＝照舊用 `#6b3f2a`（不冒煙）；街區精靈快取鍵帶閥門。

**不改**：馬廄精靈的任何像素（煙囪、煙囪帽顏色都不動，`fp.json` 應零變動）；`chimVisible613` 的規則；其他立面；煙的畫法。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `mewsSmoke671`**（煙霧常駐）：馬廄精靈 `smoke608` 有 1 個點、那一點正下方的像素就是登記的顏色；關閥門時 0 個；開關閥門精靈像素逐一相同；快取鍵帶閥門。
2. **守衛 `probe671.js`**：同上，外加其他 5 種英式立面（`ukTerrace`、`ukSemi`、`ukVictorian`、`ukMansion`、`ukHighStreet`）的冒煙點開關閥門完全相同；種子城裡的馬廄起點格（住宅 lv1 v=5、是街區起點、畫出來是 `ukMews`），冒煙點查詢 `smokeViewSrc626`（畫煙時用的同一條）回傳的點數：現況 0、修後每棟 ≥1、關閥門 0。
3. **煙霧** 3 連跑綠；`fp.js --check` 全綠、零變動。

## 4. 施工

- `REG.ukMews` 登記冒煙點改用煙囪帽的顏色 `#a35a37`；閥 `__noMewsSmoke671`＝舊色；`getBlockSprite547` 快取鍵加 `_ms0`。
- 自檢 `mewsSmokeSelftest671`（5 項）掛進 `smoke.js`；守衛 `probe671.js`。
- 版本 v13.76／T671。
