# T544 — 天際線穿刺（禁止中等高寬方柱）

**輪次**：r13
**基線**：T543 v12.96
**業主**：建築全部更新換代；問停就繼續。

T543 中央出現一座金褐針塔，但 z=0.68 核心仍是同寬板樓高原。原因：十二型裡太多「hw 16–28 × h 80–140」的中等方柱，密了就融。

## 驗收（動手前）

1. lv3 十二型分成三組，**禁止中等高寬方柱**：4 針（hw≤9、h≥200）、4 雙塔／三簇（兩座高度差 ≥80）、4 矮+尖頂／階梯（主體 h≤56 或明顯退台）。
2. 住宅高層必須有尖頂或煙囪；商業高層必須玻璃幕+天線／標誌，**不能只是換色**。
3. 英雄塔針型再瘦再高，遠距必須比周圍板樓高出一截。
4. `__noVariety542` 仍退回舊圖集。指紋 == `bld`。煙霧綠。自己截 after 城圖。
