## 1. 這一輪要解決什麼

r60、r62 兩次記「探針夜圖看不清夜燈」。T617 之後的美術探針查到根因**不在探針，也不在燈**：

- 晝夜色調（`index.html` 約 62192 行）午夜只乘上 `lerp([110,125,190],255,b)`，`b` 最低 0.34 ⇒ 乘數約 **(0.62, 0.66, 0.83)**，整張只暗三成多、偏一點藍。
- 夜燈用 `screen` 疊在這層上面，底色太亮，燈浮不出來。
- `daylight()` 在 `ph∈[0.75,1.25)` 整段 `b` 停在 0.34 ⇒ **一天約有一半時間**玩家看到的是這個「偏藍的白天」。

雲端出了三檔對照圖（同一種子城、同一午夜、只改這一行，臨時改、拍完已還原）：A 現狀／B 中／C 深。

**業主 2026-09-24 選 B**，原話：「選 C 會面臨特定建築細化處理……C 可能面臨特定建築的燈光細化處理，也就是不必要的燈光增加。」——C 夠黑，但窗燈少的建築會變成暗方塊，逼出一批為了夜景硬加的燈；B 看得出是夜晚、燈浮得出來，又不需要這批燈。

## 2. 改什麼／不改什麼

**改**

1. 晝夜色調改成 B 檔：夜色 `nc=[96,108,172]`，並把 `b` 從 [0.34, 1] 重新映射到 [0, 1] 再插值 ⇒ 午夜乘數正好是 `nc/255`≈**(0.38, 0.42, 0.67)**，正午 `b=1` 仍是 255（不畫）。
2. 顏色計算抽成 `nightTint619(b)`，逃生閥 `window.__noNightDepth619` 退回舊公式（逐值相同）。
3. 自檢 `nightDepthSelftest619` 掛進煙霧（純函式：端點、單調、閥門逐值還原）。
4. 版本 v13.27／T619。

**不改**

- `daylight()` 本身（`b`、`dusk`、`ph`、`d` 全不動）⇒ 所有看 `b` 的門檻（窗燈 `b<.55`、夜燈 `b<.72`、螢火蟲、蝴蝶、音效）時機不變。
- 夜燈強度、窗燈數量、任何建築精靈（`fp.js` 應零變動）。
- 晨昏橙／藍疊色（`dusk`）不動。
- 主選單標題畫面有自己獨立的晝夜公式（約 48884 行），不動。
- 市民對話泡泡（T607）畫在夜色之前，夜裡會跟著變暗；本輪**不搬**，只在近景夜圖上檢查可讀性，如實記錄。
