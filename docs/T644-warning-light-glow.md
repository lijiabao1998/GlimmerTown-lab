## 1. 這一輪要解決什麼

T636 把摩天樓（k33/k34）頂的警示燈移到精靈最高點，但燈只畫在建築層，夜裡跟樓身一起被夜色壓暗，看不出是燈。

## 2. 改什麼／不改什麼

**改**

1. 警示燈亮的那一幀（2 幀閃爍的第 0 幀）、夜深 > 0 時，把同一張燈圖推進發光層，外加一小塊淡紅光暈（4×4、#ff5a4a、α .55）。
2. 逃生閥 `window.__noWarnGlow644`＝舊式；自檢 `warnGlow644`；版本 v13.49／T644。

**不改**

- 燈的位置（T636）、閃爍節奏、白天畫法。
- 不加別的燈（業主 T619 的顧慮）。

## 3. 怎麼算做完（動手前寫下）

## 6. 施工紀錄（如實，含失敗）

- **自檢沒有真的種一棟摩天樓**：卡面寫「種一棟摩天樓看發光層多幾筆」，但發光層只在 `draw()` 裡面存在、拿不出來。改成把推燈抽成 `warnGlowPush644`，自檢用真的警示燈精靈呼叫它，再加一項確認 `draw` 裡真的有呼叫。
- **紅色像素只多 7 個**：光暈 4×4（z=1.5 時 6×6）、α .55，大部分像素過不了「紅色」門檻；6 顆燈裡畫面上看得到 2 顆（其餘在畫面外或被 T629 擋掉）。放大對照是暗紅點變成亮紅方塊。
- **守衛第一版午夜紅色像素沒關紅綠燈**：紅燈也是紅色像素，新舊兩版畫的次數不同、相位不同，會把差距蓋掉；午夜也改成關紅綠燈比，兩次跑都是 772／765。
- 遠景（`lodFar`）警示燈不閃、固定第 0 幀，所以遠景夜裡一直亮著；這是原本就有的「遠景不閃」，沒動。
