## 1. 為什麼要做這一輪（問題陳述）

T533 的卡面 §6 自己記了：

> 履歷的**點擊往返**（點名字 → 換面板 → 按返回 → 回住宅）**沒有在無頭環境驗證過**，
> 因為無頭新建城市 `pop=0`、不會生成市民。目前已斷言的是邏輯與 HTML 輸出。

也就是說：**看得到的那一半（履歷面板）沒有任何自動化證據**。這一輪把那個洞補掉。

## 2. 驗收條件（**動手前寫定**）

1. 提供一個**只給測試用**的注入鉤子，能在任意空地上造出「一棟供電住宅 ＋ 一位有履歷的市民」。
2. 鉤子跑完後，對那棟住宅按下 inspect，居民卡片必須出現該市民的可點名字。
3. 點名字 → 面板換成履歷（含姓名、年齡、生命事件）。
4. 按「返回住宅」→ 面板回到住宅檢視（含居民列表）。
5. 上述 3 與 4 是**真的 DOM 事件往返**，不是直接呼叫函式假裝。
6. 鉤子必須**自我清理**（移除測試市民與測試建築），跑完不留痕跡，可重複執行。
7. 煙霧測試綠 ＋ 這條往返斷言全過；失敗就退版換題，不帶著紅跑。

## 3. 進場探針（先量）

| 要量什麼 | 量到什麼（出處） |
|---|---|
| 住宅建築怎麼生 | `index.html` 生長迴圈：`cell.bld={k:kk,lv:1,v:pickV406(kk,1,x,y,ri(12)),age:0,pw:true,h:.6,den,we}` ＋ `tickBld.push(idx(x,y))` |
| 市民怎麼生 | `spawnCitizen()`：隨機挑 `k===1 && pw` 的住宅當 `home`，欄位 `{name,home,hx,hy,work,wx,wy,age,job,fx,fy,at,path,pi,p,ptype,stage,quote}` |
| 居民卡片在哪 | `inspect(x,y)` 內、住宅分支的 `citizens.filter(c=>c.home===homeI)`；面板寫進 `#infoBody` |
| 點擊入口 | T533 加的 `[data-life533="home|name"]`，綁在 `$('#infoBody').innerHTML=html` 之後 |
| 無頭能不能點 | 能：`smoke.js` 已在頁面內用 `element.click()` 驅動過 UI（選難度、建城市） |

**結論**：不需要真的等人口成長。直接照遊戲自己的形狀注入一棟住宅＋一位市民即可，
成本低且完全走真實的 inspect → DOM → 事件路徑。

## 5. 已知取捨（先講清楚）

把測試鉤子放進正式檔，是一個**刻意的取捨**：這個專案是單檔、沒有測試框架，
沒有鉤子就沒有辦法在無頭環境斷言 UI。緩解方式有三：

1. 鉤子掛在 `GV` 上（既有 QA 慣例），名字帶 `test` 前綴，一看就知道是測試用。
2. 鉤子不改變任何既有行為（只寫入它自己造的實體，並在結束時清掉）。
3. 逃生閥：`window.__noTestHook534` 為 true 時，兩個鉤子直接回 `{ok:false, skipped:true}`。

（主線的做法是把測試放檔案外、用斷言框架跑；實驗線單檔、沒有框架，所以走鉤子。
若之後主線要收編，這一節就是移除清單。）

## 6. 施工紀錄（如實，含失敗與自捕）

- **施工本身一次過**：兩個鉤子（`testInjectResident534`／`testUiRoundtrip534`）與煙霧測試階段 ④c
  都是單一錨點，第一批就命中；跑起來 6 步全過。**但下面三件事不是一次過。**
- **自捕 1（批次鐵律救了一次）**：治理腳本第一版把 `GAME_ANCHOR!=='T533'||GAME_VER!=='12.88'`
  的反向形式預期成 0 處，實測 **1 處** ⇒ 腳本整批拒絕寫檔、檔案維持原狀。
  這正是 T533 那次半套套用的解藥：**如果不檢查，這次又會寫成半套**。
- **自捕 2**：修正預期值重跑時，GV 出口那條用了 `apply(..., exp=0)`，
  在三元運算式裡被短路成「不執行」⇒ `build534` 出口**沒被加上**卻沒報錯。
  事後用 grep 檢查才發現，補上並重跑綠燈。**教訓：批次腳本裡的「條件式呼叫」是盲點，
  條件本身也要斷言。**
- **自捕 3**：`node smoke.js | tail -4` 只截到表頭，誤以為測試沒跑完；
  改成 grep 判定行才確認綠燈。**教訓：驗收要看判定行，不要看尾部。**
- **未盡的驗證（照實寫，不美化）**：這條往返證明的是**注入的合成市民**能走完 UI；
  「真實人口成長出來的市民」其卡片與履歷**仍未在無頭環境驗證**（需要 `pop≥8` 的城市）。
  風險不高（同一條資料結構、同一個渲染分支），但**沒驗到就是沒驗到**。
