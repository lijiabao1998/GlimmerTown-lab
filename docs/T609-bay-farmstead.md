# T609 灣城農莊：一塊田只留一組英國鄉間農莊

**基線**：`f9d22a9` T608  
**業主**：「你全部做完吧」。第五件「T605 的尾巴」的第一刀。

## 場景

T605 卡上寫「農場改磚牆石板頂農莊」，但攤開精靈看，田裡同時有：

- T276 的北美農莊套件：白農舍、紅穀倉（白框 X 大門）、白筒倉、紅拖拉機、木柵。它蓋在全部 16 種作物、48 張季節圖、生長階段圖和大農場上。
- T605 在後製鏈又往田中央加蓋一棟磚農莊。
- 大農場底圖自己還畫了一個紅方塊穀倉、雙筒倉、舊農舍、舊拖拉機。

另外農場和牧場的精靈右下角都有一大塊超出地塊的深色橢圓。`probe610.js` 在開機前攔截畫在 136×150 畫布上的大橢圓，指到 T526 的拋光後製（`polishAll526`）：它對每一張建築精靈加一個接地橢圓影，對整塊平地的農場、牧場就變成田地外的暗斑。

## 改什麼

- `farmstead610`（放在 T276 套件的位置，同一套相對錨點與倍率）：乾砌石院牆、碎石院子、磚農舍（長面朝左前受光、石板瓦雙坡頂、白框窗、綠門、山牆磚煙囪）、乾砌石穀倉（較高、大木門、山牆通風口、風向雞）、方捆乾草、英國老式灰色小拖拉機、院子前緣留門口的矮石牆。硬邊掃描線填色，冬季屋頂積雪。前半地塊留給作物。
- T282 的小件（水井、雞舍、柴垛、木車、稻草人、蜂箱）移到前半田裡，不壓新農莊；舊紅穀倉上的風向雞不畫。
- T605 田中央加蓋那一棟：不再蓋。
- 大農場底圖的紅方塊穀倉、雙筒倉、舊農舍、舊拖拉機：不畫（季節版從底圖複製，一起乾淨）。
- T526 接地橢圓：農場 22、牧場 23、大農場 53 跳過。
- 牧場的「穀倉門晝開夜閉」與家禽場雞群改成優先讀精靈自帶的座標（`door403`、`hen403`），沒帶才用舊值。這是給 T611 重畫牧場的前置，這輪畫面不變。
- 逃生閥 `__noFarm609`（boot 前設）。版本 13.20／T609。
- T605 自檢「農場是灣城農莊」原本只認 T605 的旗標，改成 T605 或 T609 的旗標其一。

不改存檔、模擬、作物日曆。
