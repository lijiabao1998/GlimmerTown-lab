## 2. 怎麼量

用 T606 留下的稽核探針 `probe606.js`（種子城、預設 5 個鏡頭、z=1.5、抓實際畫到的 112 棟，街區精靈 106 棟），同一批建築跑兩種模式：

- **原樣重放**（預設）：每一層直接畫在建築上，不經過遊戲的閘門與剪影剪裁。
- **生效模式**（`--effective`）：照遊戲真的繪製路徑：`legacyOverlay606(s)` 閘門（街區精靈不吃舊疊畫）、主體層剪影剪裁、加上貼牆層 606。

## 4. 結論

- 兩份數字沒有矛盾，量的東西不同：T663 量的是「這些層如果不經過閘門直接畫會落在哪」，T606 量的是遊戲真的畫出來的。
- **遊戲裡沒有 421–447 浮空的問題**，不需要退役或移植，也不需要業主決定。T663 卡上的待決事項到這裡結案。
- 591、593 兩層 T663 已經預設退役，種子城 16 個鏡頭實測差異 0 px，跟這裡的生效模式一致（591、593 本來就被閘門擋掉）。
