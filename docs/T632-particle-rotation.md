## 1. 這一輪要解決什麼

T626 修了 T608 那條煙（工業、冬季民居、店屋），卡面 §6 記下「其他煙源與粒子還是世界座標，旋轉後照樣偏或往下飄」。讀碼確認：

- T159 粒子（`fxParts`：施工塵土、拆除碎屑、火花餘燼、落葉、櫻花瓣、卡車尾氣、T175 街道蒸汽）由 `spawnFxAt` 推入，位置與速度都在**世界等距座標**：往上＝`wy` 變小（火花 `vy−=14`、蒸汽 `vy−=2.5`），往下＝`wy` 變大（碎屑重力 `vy+=90`、落葉 `vy=9～15`）。
- 畫的時候經 `isoW2V(wx,wy,偏移)` 轉到畫面。旋轉 180° 時畫面的上下整個顛倒：**火花往下掉、碎屑往上飛、落葉往上飄、蒸汽往下沉**；旋轉 90°／270° 時全部往側面跑。
- `smokes` 裡 T608 以外的煙源（電廠蒸汽、暴亂住宅的煙、T401 收割揚塵與秋末燒茬煙柱）也一樣：在世界座標往上飄，rot 2 往下沉。
- `isoW2V` 在 rot 0 是恆等轉換（`w2v` 不動座標），所以預設視角看不出問題。

## 2. 改什麼／不改什麼

**改**

1. `spawnFxAt`：推入時把起點換成 view 座標——用畫的時候**同一個** `isoW2V` 與同一個高度偏移（落葉 −6、蒸汽 0、其餘 16）——並記下當時的視角；速度直接當畫面方向（往上就是畫面往上）。
2. `fxParts` 的繪製：view 座標粒子直接畫、不再經 `isoW2V`；視角換了，舊角度的粒子當幀清掉（同 T626）。
3. `smokes` 裡 T608 以外的推入點（電廠、暴亂、T401 兩種）：推入時同樣換成 view 座標，沿用 T626 的 `view626` 標記、更新與繪製（T626 已處理）。
4. 逃生閥 `window.__noPartView632` 退回世界座標（兩種粒子一起）。
5. 自檢 `partView632` 掛進煙霧。版本 v13.37／T632。

**不改**

- 粒子的數量、顏色、壽命、速度大小、生成頻率。
- 彩帶（`confetti`，本來就在畫面座標）、雨（畫面座標）。
- T608 那條煙（T626 已修）。

## 3. 怎麼算做完（動手前寫下）

1. **rot 0 逐值不變**（自檢）：rot 0 時，每一種粒子推入後的位置與修正前逐值相同（`isoW2V` 恆等），所以預設視角的畫面不會變。
2. **四個旋轉方向都對**（自檢）：rot 0～3 各推一顆火花、一片落葉、一團蒸汽、一顆碎屑、一團電廠蒸汽，推進 0.3 秒後量它在畫面上的位移：火花、蒸汽、電廠蒸汽 **y 為負（往上）**，落葉、碎屑 **y 為正（往下）**，四個旋轉都一樣。**關閉閥門時 rot 2 至少有兩種方向顛倒**（守衛有效）。
3. **起點對得上**：rot 1～3 時，粒子起點（view 座標）與修正前第一幀畫出來的位置相同（只改後續移動，不改出生點）。
4. **畫面**（`probe632.js`，種子城有街道蒸汽的路段，rot 2）：推進幾秒後，修正前後各拍一張，並量畫面上蒸汽粒子的平均 y 位移方向；修前修後給業主。
5. **煙霧**：雲端 3 連跑綠；GitHub Actions 綠；Pages 自動部署。
6. **指紋**：`fp.js --check` 綠（T631 之後雲端已可全綠；粒子不在 SPR 與超街區快取）。

- 種子城這一天是秋天，畫面上的落葉最多（31 片）；火花、碎屑只在火災與拆除時出現，城裡當下沒有，靠自檢驗。

  1. 車流、行人、船隻不是粒子，不在本卡範圍；旋轉下的位置由各自的系統負責，沒逐一看。
  2. 雨、彩帶本來就在畫面座標，沒動。
