# T586 — 幀率基線台可信化（中位數取樣＋比值制棘輪）

**輪次**：r35　**基線**：T585（commit 7d3a46f）　**狀態**：完工

## 背景

T584 的 perf 台（單次 2.4s 取樣/場景）在 r34 背靠背兩輪實測搖擺 ±50%
（day_noon 52.6→31.1 fps），其「夜景慢 30%／rot1 慢 16%」兩個發現無法重現。
本卡把量測方法修到可用，再用可信數字結案這兩個問題。

## 改什麼（僅 perf.js／perf.json，零遊戲代碼變更）

1. **輪替式取樣**：`--rounds`（預設 5）輪 × 每場景 `--sample`（預設 1.6s），
   場景間輪替把熱節流／背景負載漂移均攤；每場景取 5 輪**中位數**。
2. **比值制棘輪**：各場景 fps ÷ 同 run 的 day_noon fps 存為 `ratio`；
   `--check` 比比值（門檻 25% 不變）。day_noon 缺席時退回絕對比。
   動機：絕對 fps 跨 run 搖擺 ±40%（機器 regime），同 run 內比值實測穩定。

## 驗收與結論（動手前寫死：兩問題以「同 run 比值」複核）

- **夜間懲罰：不存在。**夜/日比值實測 0.86／0.93／1.00／1.016（四輪），
  遠小於 T584 宣稱的 -30%。夜景場景與日間同級。
- **rot1 不對稱：不存在。**rot1/日比值 0.93–1.16、rot3/日 1.05–1.29，
  兩旋轉角與 rot0 同級；T584 的 -16% 為雜訊。
- `perf.js --check` 比值制全綠（exit 0），棘輪可用於之後每輪收束。
