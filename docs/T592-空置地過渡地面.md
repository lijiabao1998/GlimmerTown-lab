# T592 — 空置地過渡地面（「正在變成城市」的中間態）

**輪次**：r41　**基線**：T591（d14c2aa）　**狀態**：完工

## 背景（業主驗收點「地面不再是空白底板」）

探針：空置 zoned 格（`t.zone&&!t.bld&&!t.ruin`）在地面烘焙層只畫
`SPR.zone[t.zone]` 半透明覆蓋（50% alpha），底下裸草——城市裡的「等長出來的地」
讀作空白。同層既有 T428（建築鄰地使用痕跡）／T447 巷弄生活可並列。

## 改什麼（draw-side 地面烘焙層；streetHash 決定性；不碰 sprite/模擬/save）

`drawEmptyLot592(gc,x,y,sx,sy,z,zn)` 掛在 zone 覆蓋之後：

- **整地土斑**（全型）：土色橢圓 1~2 塊，I 區土色深、C 區灰、R 區帶草黃。
- **雜草/植痕**（R 偏多）：2~4 叢草 tuft。
- **建材堆**（C/I）：磚垛/管材/木料堆 1~2 組（疊矩形＋投影線）。
- **基礎板**（C/I，hash<.5）：55% 縮放混凝土菱形＋深色邊＋鋼筋頭點——「快蓋了」。
- **臨時車轍**（鄰路，hash<.6）：兩條平行輾壓痕。
- `__noLot592` 逃生閥；lodFar（z<1）跳過。

## 驗收（動手前寫死）

1. 同 run A/B（`__noLot592` on/off 各 forceDraw toDataURL）畫面必須有差異。
2. fp.js --check 零變動（地面烘焙非 sprite）。**實測 exit 0**。
3. perf --check 綠。**實測 exit 0**。
4. 煙霧測試綠＋日間樣張（空置格可見過渡地貌）。**實測綠**。
