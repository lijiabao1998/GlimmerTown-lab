# T699 — 英美立面街屋加風化（B：照一般街區同濃度，畫在真牆上）

**輪次**：r146
**基線**：`4b112d9`（v14.02／T698）
**狀態**：卡面先推，施工中
**業主決定**：2026-09-30 決策單第十二批第 2 版 **12-2 選 B**（「2B好了」；`docs/DECISIONS.md`）。

---

## 1. 這一輪要解決什麼

T606 的貼牆風化（簷下灰線、雨漬、牆腳污垢）把英美立面街區（`f577:` 樣式）整個排除。八種立面街屋因此比旁邊的一般街區新：白灰泥排屋、半獨立屋、紅磚連棟屋、馬廄街屋、大宅、高街旅館、芝加哥樓、布朗石。

## 2. 改什麼／不改什麼

**改**：照決策單原型第十三版 `scratchpad/b12/weather/patch12.js` 的 B 路徑（`__x12Weather=2`、不開煤煙）施工。

- 立面繪製器畫牆身時，登記真正的牆面；門、窗、店面、凸窗都避開。
- 風化照一般街區同一套硬像素筆觸、同濃度，畫在登記到的牆身上。
- 繪製時照正前方會蓋住它的東西修剪，碎點不畫。
- 逃生閥 `window.__noFacadeWx699`（執行期）＝回現況，跟原檔逐像素相同。

**不改**：
- 煤煙（C）、再舊一級（D）、舊牆盒子法、量測／校準旗標：一律不進遊戲。
- 一般街區的風化、精靈本身。

## 3. 怎麼算做完（動手前寫下）

1. **自檢 `facadeWx699`**（煙霧常駐）：
   - 閥門關時，某棟立面街屋的精靈有登記到的牆面，貼牆層真的畫出像素；
   - 閥門開時不畫；
   - 任何像素都不變亮；
   - 真的 `draw(.016)` 一次不擲錯。
   - T606 的 `wallDetailSelftest606` 若有「立面街屋不疊貼牆層」一條，改成在閥門下驗、卡上記明。
2. **一次性核對**（同一份 v14.02、同一局亂數、水面釘同一幀）：
   - 新版（閥門關）對原型 B（`__x12Weather=2`）：決策單的鏡頭逐像素相同，至少近景、中景、z1、兩個 z4 特寫；
   - 閥門版對原檔 v14.02：同鏡頭逐像素相同。
3. **守衛 `probe699.js`**（種子城，全城設 300 歲）：
   - 近景 z2 鏡頭新舊不同的像素 >5,000；
   - 變亮的像素 0；
   - 差異只落在立面街屋的精靈範圍裡：立面街屋的外接框之外 0 像素差。
4. **煙霧** 3 連跑綠；`fp.js --check` 全綠（風化是繪製期疊層，不動精靈）。
5. **效能**：同一局量 z1、z2 每幀時間，新版對閥門版，照實記在卡上。
