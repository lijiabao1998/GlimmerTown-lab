# T633 — 兩個街區認領同一格：超街區切分重疊，兩張建築精靈疊在同一塊地上

**輪次**：r80
**基線**：`9642bd5`（v13.37／T632）
**狀態**：🚧 施工中（卡面先單獨提交，驗收條件寫在動手之前）

## 1. 這一輪要解決什麼

旋轉稽核（種子城住宅近景 z=2，rot 3）看到一棟藍色平頂樓被後面的紅屋頂民居蓋掉半邊，民居屋頂上還有一條垂直切痕。回到 rot 0 看同一區：一排小屋被藍色平頂樓從中間穿過，長條鋸齒屋頂壓在小屋上。業主截圖圈的「建築物交疊」還有這一個來源沒修（T624 修的是同一張精靈裡量體的前後順序）。

進場探針（暫存腳本，不進版本庫）：

- **逐點反查**畫出來的精靈：rot 3 那一塊是 (9,9) 1×4、(8,10) 4×1、(7,11) 4×1、(10,8) 1×4 四個住宅街區的分條互相覆蓋。其中 (9,10) 同時屬於 (9,9) 的 1×4 與 (8,10) 的 4×1。
- **根因**：`rciBlockOrigin547` 的起點規則是「左、上鄰格不是同類」，每個起點各自往右下貪婪長成矩形，**彼此不知道對方**。同類區是 L 形或十字形時，兩個起點的矩形會蓋到同一格，兩張街區精靈就畫在同一塊地上。深度排序只決定誰蓋誰，換一個旋轉就換一個贏家：rot 0 看起來是一排屋子穿過另一排，rot 3 看起來是樓被切掉一半。
- **全城統計**（種子城 924 格住商工建築）：**51 格被 2～3 個街區同時認領**（商業 lv2 26 格、住宅 lv2 12 格、商業 lv3 8 格、工業 lv1 4 格、商業 lv1 1 格）。
- 另有 368 格沒有任何街區負責畫：T603 聯排截斷和同一條起點規則留下的空格。這就是 D0「看不見的建築」，業主還沒挑檔，本卡不動。

## 2. 改什麼／不改什麼

**改**

1. 超街區切分改成**依掃描序認領**（y 先 x 後，與繪製迴圈同序）：起點規則不變；先到的街區認領它的格子，後到的街區長大時**不准伸進已被認領的格子**（正方形、往右、往下三步都一樣），之後照原本的 T603 聯排截斷、T604 工業上限、4×4 上限。
2. 切分全圖算一次、存起來（新函式 `rciPart633`），`rciBlockOrigin547` 查表。繪製迴圈、冒煙點、泡泡、招牌、`rciAbsorbed555` 全部拿到同一個切分。每次 `draw` 開頭作廢；查詢格的建築物件或類別、等級、變體與存下時不同（自檢種地、拆建）也會重算。
3. 逃生閥 `window.__noPart633` 退回各起點各自長（舊行為）。
4. 自檢 `part633` 掛進煙霧。版本 v13.38／T633。

**不改**

- 起點規則、4×4 上限、T603／T604 截斷、街區精靈本身（block559 指紋不變）。
- 沒有人畫的格子（D0）照舊不畫。後到的街區變小，會多出少數這種空格（探針估 +12 格），等 D0 挑檔後一起處理。
- 誰先到只看掃描序（y 小的先、同一列 x 小的先），不比大小。

## 3. 怎麼算做完（動手前寫下）

1. **零重疊**（自檢，煙霧常駐）：煙霧當下那座城，所有會畫出來的街區矩形兩兩不重疊（每格最多被一個街區認領）。
2. **十字形**（自檢）：種一條 1×4 直排，再種一條穿過它的 4×1 橫排（住宅 lv1）。修正後直排完整、橫排不含交叉格；**關閉閥門時兩者都含交叉格**（守衛有效）。
3. **矩形區不受影響**（自檢）：種一塊實心矩形同類區，修正前後切出來的街區逐一相同。
4. **消費端一致**（自檢）：同一個起點，冒煙點（`smokeViewSrc626`）用的寬高與 `rciBlockOrigin547` 相同。
5. **種子城**（`probe633.js`）：重疊格 51→0；列出形狀改變的街區；沒人畫的格子 368→實測值；住宅近景 rot 0／rot 3 修前修後樣張與差異像素，給業主。
6. **效能**：住宅近景 `forceDraw` 平均耗時，修前修後差距在量測雜訊內（切分每幀只算一次）。
7. **煙霧**：雲端 3 連跑綠；GitHub Actions 綠；Pages 自動部署。
8. **指紋**：`fp.js --check` 全綠（精靈沒變）。
