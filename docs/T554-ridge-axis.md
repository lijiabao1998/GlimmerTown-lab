# T554 — 長廳脊線沿長邊

**輪次**：r23
**基線**：`2695999` T553 v13.06
**業主**：繼續。宏觀先。T553 尖頂對了，但所有山牆朝同一方向，長廳看起來像對著鏡頭的帳篷。

## 驗收（動手前）

1. `bw > bh+1` 的超街區：脊線沿長邊，鏡頭看到的是長坡不是前三角。
2. `bh > bw+1`：維持前山牆（T553）。
3. 近方形：用變體 `v` 切兩種朝向，不要整城平行帳篷。
4. 工業鋸齒沿長邊加密（齒數跟長邊走）。佔地仍 6×7，不吞路。
5. 煙霧綠。自己截 after，對照 T553。

## 不改

存檔、人口、就業、同 k 合併、退台、夜燈。

## 逃生閥

`window.__noRidge554`：全部回到 T553 前山牆。

## 施工

- `ridgeAxis554(bw,bh,v)`：寬廳 axis=1（脊沿長邊）、深廳 axis=0（前山牆）、近方形用 `v&1`。
- `pitchPara547`／`sawtoothPara547` 吃 axis；axis=1 時山牆在 W–N／S–E。
- 長邊廳的 `pitchH` 用 `max(bw,bh)` 算，避免 6×2 坡度淺到讀成平板。
- 工業齒數 3–7，沿長邊切。
