# T587 — 屋頂暗灰提亮（合併塊配色多樣化）

**輪次**：r36　**基線**：T586（commit 0d89ae8）　**狀態**：完工

## 背景

T582 像素普查的量化結論（probe582b）：T577 接手的合併塊主導色為屋頂灰
`#4c4845`（mainStreet）/`#4a4643`（chicago），k=2 legacy 平頂為
`shade(pal.dark,8)`（暗藏青 #263b55 系）——業主「全城同一暗灰色調」的來源。
本卡只動這三個色源，不做全面重調色。
