## 1. 這一輪要解決什麼

業主：「溫室的 63_1_1、63_1_2 不行，太簡陋了，並且美術素材朝向不對」。兩個變體都是面向螢幕的正面立面，不是等距 2:1；只佔地塊一小條；地面影子比房子大；夜裡只有幾條紫線。

## 2. 改什麼／不改什麼

- k63 v1 改畫荷蘭式連棟 Venlo 玻璃溫室群，v2 改畫維多利亞式溫室（取材邱園 Palm House）；等距、看得到左右兩個立面、佔滿大半個 2×2 地塊；夜圖是玻璃透出的平色補光。
- v0 不動（業主沒點名）；精靈尺寸維持 136×150。
- 逃生閥 `window.__noGreenhouse702`＝回舊畫法。

**不改**：模擬數值以外的玩法；新地標的施工動畫走 T700 通用施工（沒有專屬施工檔）。

## 3. 怎麼算做完（動手前寫下）

1. 閥門開時 v1、v2 跟舊圖逐像素相同；閥門關時是新圖。
2. 新圖實心像素不貼畫布邊、夜圖只在白天有像素的地方、地塊覆蓋率明顯高於舊圖（照實記數字）。
3. 煙霧 3 連綠；`fp.js --check --expect=bld` 只動 `bld.63_1_1`、`bld.63_1_2` 兩片，之後重寫 fp.json 基線。
4. 樣張：v0／v1／v2 精靈日夜對照、種在城裡的近景日夜，修前修後並排。
