# GLM-002 — 工業牆面歲月：舊牆廣告（ghost signs）＋磚牆修補

**分支**：`glm/alleys-riverside`　**前卡**：GLM-001（已推 origin）
**狀態**：完工（含施工紀錄）

## 查證（業主規則：聯網檢索）

[Wikipedia/Ghost sign](https://en.wikipedia.org/wiki/Ghost_sign)：手繪牆廣告盛行於
1880s–1950s，**數十年間褪入磚面**、多代廣告互相疊壓、漆面剝落、字跡殘影、
顏色沁磚。工業大牆是城市裡最大的空白畫布；T593 卡面已宣告「工業屋＝漆掉
重漆的舊牆廣告」但未實作——本卡補上，無人做過、零重複。

## 改什麼（draw-side 微雕波新層；streetHash 決定性；零 R()；不入 save）

`drawGhostAdsGLM2(g,o,bd,s,bx,by,z,drawA)`：k=3（工業）age≥40，hash 50%：

- **舊牆廣告板**：米白底（alpha 隨 age 降至 .18）＋2~3 行字跡殘影（褪紅/藍/赭橫條）
  ＋**底下一層更淡的上一代廣告框**（多代疊壓）＋1~2 塊剝落露磚＋下方垂漬
- **磚牆修補塊**（獨立 hash）：1~2 塊新磚色小矩形＋磚縫線（修補痕跡）
- `__noGhostGLM2` 逃生閥；`__tGLM2GhostCount` 計數；detailPermit432 層 594（li 表補映射）

## 驗收條件（動手前寫死）

1. 同 run A/B（閥 on/off）diff=true、計數 ≥1。
2. `fp.js --check` 零變動；`smoke.js` 綠。
3. 近景樣張：工業牆可辨識褪色廣告與修補塊，無越格無怪線。

## §施工紀錄

- **架構發現**：T606 量測到舊疊畫層 37–100% 像素浮在建築外（業主「浮空/怪線」痛點
  的根因），v13.60 已把牆面細節改為貼牆層 `drawWallDetail606`＋`wallCache606`
  （畫進 `t5.wall` 記錄的牆面、T624 的 occ 自動讓位）。本卡改掛**新系統**：
  `paintGhost606` 照 `paintWeather606` 同款 faceKit API 寫，零浮空零越格。
- 守衛：A/B diff=true、cnt=31 棟工業牆命中（計數器初版寫錯 `put()` 無回傳值，
  已修）；fp 零變動；煙霧綠。
- 沒做成的事：①深色牆上米白廣告對比偏含蓄，要不要提 alpha 屬觀感出圖給業主；
  ②多代疊壓目前 2 代，真實牆可 3+ 代；③字跡殘影是抽象橫條，非可讀字。
