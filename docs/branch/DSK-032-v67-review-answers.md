## 第三，物流系統能不能真的運作？

可以，**在影子層**：

```
ledger 建批次（batch-A, qty 7）
→ 公路（053，3 步）
→ 換裝（057 TRANSFER）
→ 鐵路（054，4 步；受 055 路權與斷軌約束）
→ 到站自動 HANDOFF 結算（revision 3, state HELD）
→ 帳本 conserved true、qty 7 不變
```

- 無路權 → `authority:no-authority`；斷軌 → `authority:track-broken`（都實測擋住）。
- **不動正式經濟**：不寫金錢／商品庫存／人口／客流／存檔。
