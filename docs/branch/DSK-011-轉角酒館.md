## 2. 取材（真實世界，2026-09-27 聯網檢索）

倫敦維多利亞轉角酒館的共同特徵（CAMRA／Victorian Web 等描述）：
| 事實 | 用在精靈哪一處 |
|---|---|
| **斜切角（canted／angled corner）入口**，兩側立柱（Corinthian／凹槽柱、複合柱頭） | 正面斜角做門斗＋兩側立柱與柱頭 |
| **一樓滿鋪釉面磚**（glazed tile，常有圖案）、**花崗岩壁柱** | 一樓蔥綠釉面磚牆＋奶油橫帶＋花崗岩色壁柱 |
| **切割／蝕刻玻璃**窗（常有 "Saloon Bar" 等字樣） | 大面蝕刻玻璃窗（白線刻紋＋中央刻字塊） |
| **屋頂瓮形飾（urn finials）**（Ten Bells 有 12 座） | 女兒牆上 3 座瓮形飾 |
| 街角弧面（curving façade）、樓上磚造＋推拉窗 | 量體兩面＋樓上紅磚與推拉窗 |
| 吊招（hanging sign on iron bracket） | 斜角上方鐵架吊招 |
實例：The Washington（Belsize Park, c.1865）、Ten Bells（Spitalfields）、Viaduct Tavern（1874）、Princess Louise（1872）。檢索未回傳可引用網址，故不列連結。
