# GROK-001 — 平地成林收一收（T655 遺留①）

**卡片號**：GROK-001（分支寫入者不佔 T 號；合併進 `main` 時由 main 寫入者配 T 號）
**基線**：`3f0bbad`（r102／v13.60／T655）
**狀態**：完成、綠燈。預設甲＝現況，不改畫面。乙、丙等業主挑。
**分支**：`grok/grove-mix`（只推這條分支，不推 `main`、不自己合併）
**來源**：T655 卡面「看得出來的問題」——平地清單 13 種仍雜，一片平地林會楓紅、紫葉、鳳凰木並排。要收得調 T652 的七成五或區塊大小，屬觀感，出圖給業主選。DSK-001 已做遺留②（冬季），這張不碰季節。

## 1. 這一輪要解決什麼

畫樹時每 5×5 格一個主樹種，75% 照主樹種、25% 照原種類。平地清單 13 種，相鄰區塊主樹種不同，再加那 25%，近看就是幾種顏色並排。

## 2. 改什麼／不改什麼

**改**：`groveTree652` 讀 `groveMixGROK1()`。

| 檔 | 內容 | 預設？ |
|---|---|---|
| 甲 | 5×5、75%（＝T652／T655 現況） | **是。不設旗標就是甲** |
| 乙 | 5×5、90%（雜樹少，區塊邊界仍會換種） | 否。`window.__groveMixGROK1='b'` |
| 丙 | 10×10、90%（一大片同一種） | 否。`window.__groveMixGROK1='c'` |

**不改**：存檔的 `t.tree`、地形分類、樹種清單、季節、冬季分支、`GAME_VER`／`GAME_ANCHOR`／開場版本字、`AUTORUN-LOG.md`、`fp.json`、`docs/DECISIONS.md`。`__noGrove652` 仍整段關掉成林。

## 3. 怎麼算做完（動手前寫下）

1. 自檢 `groveMixGROK1`：預設甲與手算的 5×5、75% 逐一相同；乙在一個 5×5 裡主樹種 ≥80%；丙在對齊的 10×10 裡只有一個主樹種、100 格裡 ≥80 格是它。
2. 既有 `grove652`、`terrainTree655` 煙霧仍綠（預設路徑沒變）。
3. `node smoke.js` 三連綠。`node fp.js --check` 零變動（只改畫哪一棵，不改精靈像素）。
4. 平地同一鏡頭甲／乙／丙三張，放卡面。

## 4. 施工

`groveTree652` 改讀 `groveMixGROK1()`。不設 `window.__groveMixGROK1` 時區塊 5、門檻 0.75，與 T652 相同。`'b'` 是 5 與 0.90，`'c'` 是 10 與 0.90。自檢 `groveMixSelftestGROK1` 掛進 `smoke.js`。像素守衛 `probeGROK1.js`。

沒動 `GAME_VER`、`GAME_ANCHOR`、`AUTORUN-LOG.md`、`fp.json`、`docs/DECISIONS.md`。
