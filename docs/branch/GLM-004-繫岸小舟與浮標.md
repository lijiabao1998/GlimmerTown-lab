# GLM-004 — 繫岸小舟與浮標（水岸生活感收尾）

**分支**：`glm/alleys-riverside`　**前卡**：GLM-003（b16c394）
**狀態**：完工（含施工紀錄）

## 查重

T361a `lifeShip`（貨輪/遊艇/釣船）與 T64 `cargoShips` 都是**航行中**的船；
本卡是**繫岸靜態**小舟（舢舨/划艇，1~2 人划尺度）＋浮標——定位不同、零重複。
與 GLM-001 岸壁繫船環形成「環→繩→舟」完整敘事。

## 改什麼（地面烘焙層 draw-side；streetHash 決定性；零 R()；不入 save）

`drawMooredBoatGLM4(gc,x,y,sx,sy,z)`：**水面格**（t.t===0）且鄰陸格為都市岸
（格 3 內有建築/路軌，同 GLM-001 判定）：

- **繫岸小舟**（12%）：舟體尖橢圓剪影（10~14px，深棕/灰白兩款）＋內舱陰影＋
  水線暗邊；**纜繩** 1px 由舟首連到陸側邊緣（對岸 GLM-001 繫船環方向）
- **浮標**（深水格 2%）：小柱浮標（紅/白 2 款）＋微光點（夜由既有夜燈層負責，不另畫）
- 幾何鐵律：全部圖元內縮該水面格菱形內；舟身長軸平行於岸緣——零越格
- 逃生閥 `window.__noBoatGLM4`；計數 `__tGLM4BoatCount`（烘焙清零區）

## 驗收條件（動手前寫死）

1. 同 run A/B diff=true、計數 ≥1。
2. `fp.js --check` 零變動；`smoke.js` 綠。
3. 深水窗（遠離岸）零污染；近景樣張舟/繩/環可辨識。
