# GLM-003 — 疊畫浮空稽核與收編（穿模/怪線根除）

**分支**：`glm/alleys-riverside`　**前卡**：GLM-001/002（已推 origin）
**狀態**：卡面（動手前）

## 動機（業主硬約束：不要穿模、不要奇怪的線、不要非法交疊）

T606 已證實舊疊畫層 37–100% 像素浮在建築外，並把牆面細節收進貼牆層
（drawWallDetail606，GLM-002 已照新系統掛）。但 `draw()` 內 447x 系列
（IndustrialShift/CommService/ParkUsage/ResYard/IndFooting/SchoolFront）**仍在
`ovClipEnd606` 之後用裸 ctx 畫**——沒有剪影裁切，理論上仍會浮空。

## 做法

1. **先量**：用 T606 的 `overlayLayers606()` 重放機制跑現況，列出每層
   float/wall/other 百分比（只讀、離屏、不碰主畫面）。
2. **收編**：float% 超過門檻的層，逐一搬進 `ovClipBegin606/ovClipEnd606`
   剪影裁切（與 424/591/593/426 同款），或改寫成 wallCache606 貼牆層。
3. **重測**：收編後重跑量測，float% 應歸零或降至無害級。
4. 每層收編單獨 commit（一次一件事），逃生閥沿用各層既有 `__noXxx`。

## 驗收條件（動手前寫死）

1. 量測報告：收編前後 float% 對照表（每層一行，可斷言數字）。
2. 收編層的 A/B diff=true（層仍生效）＋收編後層像素 100% 落在建築剪影內
   （T606 量測 wall+other=100%，float=0）。
3. `fp.js --check` 零變動；`smoke.js` 三連綠。
4. 日/夜樣張各一，目視無新怪線。
